# HackCMU 2026 grading copilot: demo data (Linear Algebra, Homework 1)

Fictional, synthetic dataset for the Codex demo/simulation. No real students, names, or grades.
Course style mirrors CMU 21-254 problem sets 1–2 (vectors, matrix products, Gaussian elimination with
labeled row operations, an applied mixing problem, RREF/rank/solution counts, span/independence). 40 points.

## Folders (feed to the system in this order)
01_assignment/                 Homework 1 Blank.pdf                the blank assignment (6 problems, 40 pts)
02_professor_answer_key/       Homework 1 Solutions.pdf            professor's worked solution, every step shown
                               Grading Guidelines.pdf              per-part points + course rules E1–E9
                               Professor Persona.pdf               notation rules N1–N9, strictness rules S1–S9, comment format
03_graded_past_submissions/    10 folders, one per student. Each has:
                                 graded_submission.pdf   the student's handwritten work with the professor's red inline
                                                         comments  [PROF: -1 E2 Row operations are not labeled.]  and a
                                                         grader summary at the end   <- upload these as "past graded examples"
                                 professor_grade.json    the same grade as structured data (per part: points, max, comment)
                                 original_submission.pdf the ungraded original
                                 page_map.json           which PDF pages each question is on
04_ungraded_new_submissions/   2 folders. Each has submission.pdf + page_map.json only.   <- these are the "new" uploads
05_HIDDEN_answer_key_for_ungraded/   the professor's grade for the 2 ungraded students. NEVER give this to the system.
                                     Compare the system's output against it after the run.

## What the two ungraded submissions test
s08 Hiro Tanaka:   every answer correct, but Problem 3(a) has no row-operation labels and 5(b) states the rank with no
                   reason. The right outcome is deductions for missing work, not a perfect score. This is the key demo case.
s23 Wesley Park:   mixed: forgets the 1/2 in 1(b), squares B entrywise in 2(f), claims 0 solutions impossible in 5(c),
                   and uses a determinant instead of row reduction in 6(b), which the rules say gets FULL credit (E9).

## How the graded set teaches the professor's style
The 10 graded examples include: two perfect papers; unlabeled row operations penalized even with correct answers
(s22, s29); missing units (s27); bare answers with no work (s21, s22, s24, s27); arithmetic slips deducted once
and followed through (s06, s10, s28); conceptual errors (s22, s24, s29); a skipped problem (s21); crossed-out
restarts (s09). Every deduction cites a rule code from the guidelines/persona.

## Provenance
Problems and solutions were written from an exact-fraction answer key. Students were generated by agents from a seeded
design (profile + injected error per part), then graded BLIND by a separate "Prof. R. Castellano" agent that saw only
the submission, the solution, the guidelines and the persona. Where the blind grade differed from the design, the
difference was reviewed by hand; the professor's grade is the one shipped. Generation workspace with all tooling:
~/code/HackCMU2026-simdata (tools/answer_key.py, gen_manifest.py, render_pdf.py, build_students.py, apply_grades.py).
